# 커밋 컨벤션 (Conventional Commits)

- 작성일: 2026-08-03 / 상태: 확정
- 형식: **`타입: 내용`** (한국어). 주요 변경은 본문에 D-번호 참조.
- 판단 기준: **"이 커밋으로 시스템이 할 수 있는 일이 늘었나?"** → 늘었으면 feat.

| 타입 | 의미 | 예시 |
| :---- | :---- | :---- |
| feat | 기능 추가 — 동작이 새로 생김 | `feat: Flyway 도입 및 DB 스키마 구축 (D-016)` |
| fix | 버그 수정 | `fix: 예약 수량 계산 오류 수정` |
| docs | 문서만 변경 | `docs: ERD v1.0 확정, D-014~016 기록` |
| chore | 잡무 — 설정·정리 (기능 무관) | `chore: backend 프로젝트 초기 세팅` |
| refactor | 동작 그대로, 코드 구조만 개선 | `refactor: 재고 차감 로직 분리` |
| test | 테스트 코드 추가·수정 | `test: FEFO 차감 단위 테스트` |
| style | 포맷팅 등 의미 없는 변경 | `style: 코드 정렬` |

- 자주 쓰는 4개: **feat / fix / docs / chore** — 이걸로 90% 커버.
- 여러 성격이 섞이면 대표 타입 하나 + 본문(`-m` 반복)에 세부 내역.
