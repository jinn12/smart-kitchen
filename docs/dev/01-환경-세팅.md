# 개발환경 세팅 체크리스트 — Smart Kitchen

- 버전: v0.1 / 작성일: 2026-07-31
- 전제: **회사 노트북(전자정부·이클립스·자바8·톰캣) 보호가 최우선.** 전역 설정을 건드리지 않는다.

---

## 0. 구조와 도구 (결정 사항)

- 모노리포: `E:\smart_kitchen` 아래 `docs/` `backend/` `app/`
- 백엔드: Kotlin + Spring Boot 4 → **IntelliJ IDEA Community** (무료)
- 앱: Flutter(Dart) → **VS Code** (+ Android Studio는 SDK·에뮬레이터 관리용)
- 통신: 앱 → 백엔드 REST API (JSON)
- **Docker Desktop은 설치하지 않는다** — WSL2/Hyper-V를 건드려 가장 침습적. 배포 이미지는 GitHub Actions가 빌드
- 코드는 E:(이동식 디스크), SDK·빌드 캐시는 C:\dev — USB 디스크 빌드 속도 문제 회피
- ⚠️ 디스크 관리에서 이동식 디스크 드라이브 문자를 **E:로 고정** (바뀌면 IDE 프로젝트 경로 깨짐)

## 1. Git + GitHub 1차 커밋 (문서만 먼저)

- [ ] GitHub에 `smart-kitchen` 리포 생성

## 2. JDK 21 — 전역 오염 없이

- [ ] Eclipse Temurin **JDK 21 zip** 다운로드 (installer 아님)
- [ ] `C:\dev\jdk-21`에 압축 해제 (끝. 설치 과정 없음)
- [ ] ⚠️ **JAVA_HOME·PATH 변경 금지.** 블로그에서 "환경변수 설정" 단계가 나오면 건너뛴다
- [ ] 검증: cmd에서 `java -version` → **여전히 1.8이 나와야 정상**

## 3. PostgreSQL

- [ ] PostgreSQL 17 Windows 설치 (포트 5432 기본값 — 톰캣 8080과 무관)
- [ ] DB `smartkitchen`, 전용 계정 생성
- [ ] 접속 정보는 `backend/src/main/resources/application-local.yml`에만 기록 (git 제외 대상)
- [ ] (선택) 서비스 자동 시작 끄기 — 개발할 때만 수동 시작해도 됨

## 4. IntelliJ + Spring Boot 프로젝트

- [ ] IntelliJ IDEA **Community** 설치
- [ ] [start.spring.io](https://start.spring.io) 에서 생성:
  - Gradle - Kotlin / 언어 Kotlin / Spring Boot 4.x / Java 21
  - 의존성: Spring Web, Spring Data JPA, Validation, PostgreSQL Driver
  - Artifact: `backend` → zip을 `E:\smart_kitchen\backend`에 풀기
- [ ] IntelliJ로 `backend` 폴더 열기 → **Project SDK와 Gradle JVM을 `C:\dev\jdk-21`로 지정** (전역 설정 대신 IDE가 프로젝트별로 JDK 관리)
- [ ] `application-local.yml`에 DB 접속 정보 작성 후 `./gradlew bootRun` → 기동 확인

## 5. Flutter + VS Code

- [ ] Flutter SDK zip → `C:\dev\flutter` 압축 해제
- [ ] 사용자 PATH에 `C:\dev\flutter\bin` 추가 (Java와 무관한 항목이라 안전)
- [ ] Android Studio 설치 (Android SDK·에뮬레이터용)
- [ ] `flutter doctor` 실행 → 안내에 따라 `flutter doctor --android-licenses` 등 해결
- [ ] VS Code에 Flutter 확장 설치
- [ ] `E:\smart_kitchen`에서 `flutter create app` → 에뮬레이터에서 기본 앱 실행 확인

## 6. 2차 커밋 (프로젝트 뼈대)

- [ ] `git status`로 `.gitignore`가 build/, .idea/ 등을 제대로 거르는지 확인

## 7. 최종 검증 — 노트북 무사 확인

- [ ] cmd `java -version` → 1.8 (21이 나오면 PATH가 오염된 것)
- [ ] 이클립스 실행 + 기존 프로젝트 톰캣 구동 정상

- [ ] `flutter doctor` 이상 없음
